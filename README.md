# Offline-Sprachdemo

Dies ist eine eigenständige lokale Demo und noch keine Minecraft-/Simple-Voice-Chat-Bridge.

- Vosk: deutsche Offline-Spracherkennung
- Piper: lokale Sprachausgabe
- Sounddevice: lokales Mikrofon und Lautsprecher

Die Piper-Stimme und das Vosk-Modell müssen separat installiert/heruntergeladen werden.
Der Dienst schreibt erkannte Befehle nach `latest_command.txt`.
